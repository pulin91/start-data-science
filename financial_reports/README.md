# Financial reports → Trading Comps

Pulls a company's latest report from SEC EDGAR and updates the EV bridge in the
Trading Comps workbook.

1. **Fetch** the latest periodic report (10-Q / 10-K / 20-F / 40-F, whichever
   was filed most recently), plus the latest annual report for carry-forwards:

       export SEC_USER_AGENT="Your Name you@example.com"
       python financial_reports/fetch_filings.py ORCL

   Files land in `filings/ORCL/` as HTML plus a PDF (PDF page numbers are what
   the cell notes cite), with a `manifest.json`.

2. **Extract** the EV bridge line items from the filings into
   `filings/ORCL/ev_bridge.json` (cash, debt, leases, affiliates, pensions,
   preferred, minorities, shares outstanding), each with a source note:
   filing label, line-item name as printed, and PDF page.

3. **Write** them into the workbook:

       python financial_reports/update_comps.py templates/TradingComps.xlsx filings/ORCL/ev_bridge.json

   Each cell gets its value (computed figures as visible formulas like
   `=-1200+80`), blue Aptos 10 font, the `#,##0.0;(#,##0.0);"-"` format and a
   yellow Note citing the source. Price (row 19) and the formula rows are
   never touched by this step. The workbook is recalculated with LibreOffice to catch
   formula errors.

4. **Price** (row 19): closing price from Yahoo Finance on a given date (or the
   last trading day before it):

       python financial_reports/update_price.py ORCL Oracle templates/TradingComps.xlsx --date 2026-09-25

Every note is titled "Claude Analyst" and sized so its full text shows on hover.

`templates/TradingComps.xlsx` is generated by `build_template.py`. Replace it
with your own template if it follows the same row layout.

Requirements: `pip install -r financial_reports/requirements.txt`, Chromium
(for PDFs) and LibreOffice Calc (for the recalculation check). The
environment must be allowed to reach `www.sec.gov` and `data.sec.gov`.
